# Sheath-PIC

実測Wafer電位を境界条件として軸対称RFプラズマ場を計算し、2D3Vテスト粒子Monte Carlo法で
Wafer半径別のIEDF / IADF / IAEDFを評価するデスクトップアプリケーションです。
等価回路は使わず、粒子輸送・電子エネルギー・Poisson方程式を連成します。
電子物性は、同梱されたAr断面積（LXCat / Phelps、2026年10月9日取得）から
Boltzpmpの**DC計算**で求めます。元ファイルの出典とヘッダーを保持しています。

初版は研究・モデル比較用です。10 kVの解析解による数値検証と、指定電場でのPICORAとの
IEDF / IADF / IAEDF照合を実施しました。全CCPのプラズマ電位・シース場は周期・格子未収束で、
物理精度はまだ確認できていません。結果と再現手順は[高電圧検証レポート](docs/validation/2026-10-14/report.md)に記録しています。
画面と保存結果には、未収束・解像度不足・物性範囲外・モデル近似を記録します。

## 起動

Windows、Python 3.13、[uv](https://docs.astral.sh/uv/)を使用します。
この作業環境では`.venv`と`uv.lock`を作成済みです。

```powershell
cd C:\Works\20261013_Sheath-PIC
$env:UV_CACHE_DIR = Join-Path (Get-Location) '.uv-cache'
uv sync --locked --extra cuda
uv run --locked --extra cuda python -m sheath_pic
```

`launch.cmd`をダブルクリックしても起動できます。PowerShellからは`./launch.ps1`も使用できます。
起動スクリプトは`nvidia-smi`がある環境でCUDA追加依存を読み込みます。
CPU用の環境は`--extra cuda`を省いて同期・実行できます。
初回の依存関係取得にはネットワークが必要です。
実験波形などの手元データは`data/`または`measurements/`に置くとGitの対象から外れます。
`examples/`の波形・密度は動作確認用の合成データです。
実行開始は「1 電子物性」「2 2次元RF場」「3 IEDF / IADF / IAEDF」、または「すべて計算」です。
計算は別プロセスで実行し、GUIから中断できます。

## CUDAによる場計算

「計算」タブで自動（CUDA優先）／CPU／CUDA GPUを選択できます。
CUDA 13系のCuPyとNVIDIA cuDSSを使用し、Poisson、電子・Poisson連成Newton系、
電子エネルギー式の疎行列を**FP64**で解きます。格子の疎行列構造、GPUバッファーと
記号分解を再利用し、各回では数値と右辺を更新します。
CuDSSに渡す行列は行・列のスケーリングを行い、残差を検査して必要なら反復改善します。
式の組み立て、イオン流体の更新、Boltzpmp DC、MC粒子追跡はCPUで実行します。

自動選択ではCUDAが利用できない場合にCPUを使い、理由を診断に記録します。
CUDA GPUを指定した場合は、初期化失敗時にエラーを表示します。
実際のGPU名、実行時間、線形残差、ライブラリ版は結果に保存します。

RTX 5070 Ti（16 GB）での同条件比較（高電圧検証に先立つCUDA導入時の測定）：

| 格子 | RF周期数 | 現行CPU | CUDA | CPUに対する速度比 |
|---|---:|---:|---:|---:|
| 24×40 | 4 | 46.8秒 | 21.8秒 | 2.14倍 |
| 48×80 | 1 | 98.3秒 | 19.3秒 | 5.10倍 |

Ar 10 mTorr、400 kHz、負側10 kVの合成波形、初期密度3×10¹⁶ m⁻³で計測しました。
場計算の初期化を含み、DC計算と保存の時間は別です。CPUとCUDAは順番に実行しています。
24×40・4周期の相対L2差は電位0.006%、電子密度0.013%、イオン密度0.013%でした。
電子密度がピークの0.1%以上の領域でも、局所平均電子エネルギーには約1.8%の差が残ります。
時間刻み・格子の収束が未確認の探索結果であり、GPU利用は物理精度の保証にはなりません。

```powershell
uv run --locked --extra cuda python scripts/benchmark_backends.py
uv run --locked --extra cuda python -m sheath_pic.cli field --backend cuda
```

CPU/CUDAの比較結果は`artifacts/cuda-benchmark/report.json`と各場NPZに保存します。
`--nr`、`--nz`、`--cycles`、`--project`、`--output`で条件を指定できます。

最初の動作確認は「計算」タブの「粗い格子の動作確認設定」を押し、
「未収束場で粒子計算を許可（探索用）」を選んで「すべて計算」を実行します。
この短いデモは合成波形による探索です。実データの評価には、周期定常と計算解像度の確認が必要です。

## 入力と初期条件

既定条件はAr、10 mTorr、400 kHz、Wafer径300 mm、ギャップ50 mm、
初期電子密度3×10¹⁶ m⁻³、初期平均電子エネルギー4.5 eVです。
初期電子エネルギー・ガス温度300 Kは測定値ではなく、編集可能な初期仮定です。

対向電極と円筒側壁を接地します。対向電極が円筒内径と同径、側壁高さがギャップと同じとした
面積比5の理想形状は内径578.233 mmです。実装した底面外周は電場・粒子の法線流束0とする
絶縁・反射境界です。実際の絶縁面への粒子吸収・表面帯電はまだ解いていません。

表面はWafer・接地面ともSiとして記録します。二次電子放出係数は両面で個別設定できます。
既定の係数0、電子吸収率1は比較条件であり、Siの実測物性値ではありません。

### Wafer波形

「波形CSVを読み込む」で時刻列、電圧列、単位を選びます。電圧の基準は接地です。

```csv
time_us,voltage_kV
0,0
0.625,-5
1.25,-10
1.875,-5
2.5,0
```

入力は昇順・重複なしの時刻、有限な数値、設定周波数の1周期以上が必要です。
複数周期のCSVでは**最初の1周期**を使用します。周期端の不連続は診断に記録します。
列名なし、UTF-8 BOM、CSV/TSV/セミコロン区切りを扱います。
`examples/wafer_demo.csv`は−10 kVの合成波形です。実験データではありません。

### 電子密度

- 一様：1値を指定。
- 数式：`r,z,R,H`はm、`ne0`は基準密度。例：`ne0*(1+0.2*cos(pi*r/R))`。
- CSV：`r_mm,z_mm,ne_m3`。完全な矩形格子または散在点を補間します。範囲外の外挿はしません。

密度式は算術演算と`sin,cos,exp,sqrt,abs,minimum,maximum`だけを許可します。
属性アクセス、任意関数、Pythonコードの実行は許可しません。

「自己整合」では密度分布は**初期条件**であり、計算中に変わります。
「外部供給」では準中性領域に電荷中性の電子・イオン対を供給／除去し、
設定した緩和時間で目標分布へ近づけます。密度を厳密に固定する方式ではありません。
供給電子のエネルギーと粒子数は収支に含めます。

## 実装モデル

### 電子物性

`xsec/Argon_電子衝突断面積.txt`のEFFECTIVE、励起、電離をBoltzpmp 0.6.0で読み込みます。
DCのE/N走査から、平均エネルギー、移動度、励起／電離速度係数、EEDFを保存します。
EEDF端の比率が許容値を超える場合はエネルギー格子を拡張し、断面積上限内で収束しなければ停止します。
同じ断面積SHA-256、温度・圧力・ソルバー設定の計算はキャッシュを再利用します。
電子の弾性損失は、Boltzpmpの弾性衝突演算子のエネルギーモーメントから直接評価します。
EFFECTIVE断面積の補正とガス熱運動を含め、等方成分から求めます。
中性ガスから電子へ流れる負の正味損失は0とし、流体側のガス熱平衡床で補います。
この低エネルギーの扱いは近似です。修正前のDC物性キャッシュは再利用しません。

場計算では平均電子エネルギーを変数にしてDC物性を参照します。
電子拡散にはエネルギー等価温度のEinstein近似、エネルギー輸送にはMaxwellモーメント近似を使用します。
EEDFそのものを2次元で時間発展させる計算は含みません。

### RF場

- 円筒体積と面積を用いた有限体積格子。駆動電極端を格子面に合わせます。
- イオン：等温Euler輸送、電場による加速、Phelps断面積による衝突摩擦。
- 電子：Scharfetter–Gummel輸送とPoisson方程式を連成Newton法で陰的に解きます。
- 電子エネルギー：電場仕事、励起・電離・弾性損失、壁面損失、外部粒子供給と二次電子源。
- イオンCFL、加速時間、電離反応時間から時間刻みを縮小します。
- 周期端の密度・エネルギー・電位を比較して周期定常を判定します。

低圧で過大な電子ドリフト流束が出ることを防ぐ自由飛行型の流束制限を使用します。
この閉包も物理近似です。電子仕事の負成分は陰的に線形化し、適用後の仕事と生の`j·E`の差を記録します。
電子エネルギーのガス熱平衡床への補正も記録します。
極小密度で平均エネルギーが発散して周囲の輸送を不安定にすることを避けるため、
構成則に渡す平均エネルギーの分母には基準密度の10⁻⁸の下限を使用します。
電子密度自体をこの値に引き上げる処理ではありません。
下限は`numerics.electron_density_floor_fraction`で指定し、数値条件の指紋に含めます。
下限より密度が低いセルの平均エネルギーは構成則用の近似値です。
生の電子エネルギー密度も`field.npz`に保存します。
**離散式のエネルギー収支が閉じることは、物理モデルの正しさを保証しません。**

準中性の基準は`|ni-ne|/(ni+ne)<0.05`とし、隣接境界セル・電子欠乏領域を除いた
電子数重み付きの電位を代表プラズマ電位とします。
準中性領域がない位相はNaN／「準中性バルクなし」とし、0 Vを代入しません。
局所シース電圧の符号は`Vs=Vmetal−Vplasma`です。

### イオンテスト粒子

位置・速度を3次元Cartesian座標で保持し、軸対称のr,z場を補間する2D3V方式です。
位相別の電子衝突電離源と外部対供給源を、円筒体積を含めて重み付けして粒子を生成します。
密度維持モードで負の外部対供給がある場合は、流体場と同じ除去率を体積損失として追跡に含めます。
生成時のイオン速度はガス温度のMaxwell分布です。
生成源がほぼ0の場合は背景分布からの相対分布を計算し、絶対フラックスは未定義とします。

- 軌道：位相・空間の線形補間とvelocity Verlet。軸の対称性と壁面までの補間を考慮します。
- 衝突：熱運動するArとのIsotropic／Backscat。等質量の重心系運動学。
- Backscatは速度交換として扱います。別の電荷交換過程を重複追加しません。
- Wafer・上面・側壁への到達時間を加速軌道から評価し、到達時の量を保存します。
- 衝突・壁面到達・体積損失の最初の事象を選び、壁面直前の衝突も追跡します。
- セル通過距離と衝突ハザードで刻みを縮小します。
- 到達粒子のIAEDFを積分してIEDF/IADFを生成します。
- 「IEDF / IADF」タブの「角度定義」で3次元極角と符号付き断面内角を切り替えます。
- 極角は`acos(|vz|/|v|)`で0～90°。符号付き断面内角は`atan2(vr, |vz|)`で−90～90°です。
- 符号はWafer半径外向きが正、中心向きが負。断面内角は方位方向の速度を含みません。
- 軸上の`r=0`では+x方向を断面の正方向とします。角度密度の単位は**度あたり**です。
- Wafer全体・半径別のIADF/IAEDFを両定義で表示でき、選択は次回起動時にも保持します。
- 体積注入時に円筒重みを含め、フラックス評価時にはリング面積で割ります。

イオンファイルのエネルギー軸は選択可能です。既定は重心系ですが、元データの仕様確認が必要です。
断面積上限を超える衝突エネルギーでは停止し、最後の断面積を無断で延長しません。
テスト粒子の密度は背景場へ戻しません。高速中性粒子・スパッタ・表面でのイオン反射は対象外です。

## 結果と再開

`results/日時_識別子/`に以下を保存します。

| ファイル | 内容 |
|---|---|
| `project.json`, `inputs/` | 再実行用条件と入力ファイルのコピー |
| `transport.npz` | DC物性とEEDF、断面積・設定・版の記録 |
| `field.npz` | 最終完了周期の電位、電場、密度、平均電子エネルギー、生の電子エネルギー密度、イオン速度 |
| `field_diagnostics.json` | 周期誤差、保存則、物性範囲、近似の記録 |
| `checkpoint.npz` | 最後に完了した周期の状態 |
| `plasma_potential.csv` | 代表プラズマ電位と準中性領域の有無 |
| `particles.npz` | 半径別・全体の分布、到達粒子、seed、供給源 |
| `csv/` | IEDF / IADF / IAEDF、半径別フラックス、到達粒子一覧 |

場計算を中断した場合、未完了の周期を捨てて直近の完了周期から再開できます。
最大周期数を増やして「場計算を再開」を押します。
物理条件・格子・波形・断面積が異なるチェックポイントは拒否します。
粒子計算の中断後は、同じseedで最初から再実行できます。
保存済みの場と異なる物理条件で粒子を再計算することも拒否します。
境界電場の再構成を修正したため、場のモデル識別は`field_equations_version=2`です。
以前のチェックポイント・場と新しいモデルを組み合わせた計算は拒否します。保存結果の閲覧は可能です。

新しい粒子結果には極角と符号付き断面内角の両方を保存します。
CSVの`iadf.csv`・`iaedf.csv`は極角、`iadf_signed.csv`・`iaedf_signed.csv`は符号付き断面内角です。
`arrivals.csv`の`angle_deg`は極角で、`signed_meridional_angle_deg`列に符号付き角度を追加します。
旧粒子結果は極角で閲覧できます。符号付き角度には入射方向の情報が必要なため、
保存済みの場を使って「3 IEDF / IADF / IAEDF」の粒子計算を再実行してください。

未収束場での粒子計算は既定で拒否します。「探索用」を明示的に選ぶと実行でき、画面と結果に記録します。
既存結果があるフォルダーには上書きしません。

右上のテーマ選択はOS追従／ライト／ダークに対応し、`.cache/ui-settings.json`に保存します。
色は`src/sheath_pic/theme.py`に集約しています。

## CLIと検証

```powershell
uv run --locked python -m sheath_pic.cli transport
uv run --locked python -m sheath_pic.cli field --project examples/quick-project.json
uv run --locked python -m sheath_pic.cli all --quick --allow-unconverged
uv run --locked python -m pytest -q
uv run --locked python -m ruff check src tests scripts
uv run --locked --extra cuda python -m pytest -q
```

`--quick`と`--allow-unconverged`は粗い格子での動作確認・探索用です。
大きな格子で計算が完了しても、格子収束を確認したことにはなりません。

検証は、実断面積のDC計算、電位境界・離散Gauss則、電子／イオン数収支、電子エネルギーの離散収支、
衝突のエネルギー・運動量保存、無衝突一様電場のイオンエネルギー、分布の正規化と周辺分布、
seed再現性、チェックポイント再開、GUIテーマ・CSV列選択を対象にしています。
GUIの実ワーカー経路と両テーマの描画は`uv run --locked python scripts/gui_smoke.py --run`で確認できます。
CUDAを含むGUI検証は`uv run --locked --extra cuda python scripts/gui_smoke.py --run`です。
CUDA追加依存・GPUのない環境ではGPU専用テストをskipし、CPUと選択動作を確認します。
GitHubへのpush時にもWindows上で同じテストと静的検査を実行します。
CIの依存環境は[uvの公式GitHub Actions手順](https://docs.astral.sh/uv/guides/integration/github/)に従います。

高電圧で特に残る検証は、電子の非局所輸送、二次電子ビームの電離、流体イオン密度とMC密度の整合、
壁面・絶縁面のモデル、および実験波形と測定分布との比較です。
二次電子は初版では流体源近似です。高電圧での予測精度を保証する実装にはなっていません。

[2026年10月14日の高電圧検証](docs/validation/2026-10-14/report.md)では、解析解、
PICORAの指定シースでの3万粒子×5条件、連成場9条件、DC物性の分割数を比較しました。
壁面到達・軸近傍の電場・壁面直前の衝突・電子弾性損失を修正し、回帰テストを追加しています。
試験スクリプトは`scripts/validate_high_voltage.py`、外部PICの実行は`scripts/picora_reference.py`です。
PICORA自身の格子・粒子数・周期収束を満たしてから、全CCPの精度基準として採用します。
